# Python Practice — Conditionals

Small Python programs I wrote while working through the conditionals lesson of Harvard's [CS50's Introduction to Programming with Python](https://cs50.harvard.edu/python/). Each file keeps the earlier attempts as comments above the final version, to show how the code was simplified step by step.

| File | What it does |
| --- | --- |
| `compare.py` | Converts a numeric score into a letter grade (A–F) with an `if`/`elif` chain |
| `parity.py` | Reports whether a number is even or odd, using a separate `is_even` function |

## Example

```console
$ python compare.py
Score: 85
Grade: B

$ python parity.py
What's x? 7
odd
```

## Run

Requires Python 3.

```bash
python compare.py
python parity.py
```
